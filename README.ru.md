# Qt Calculator

🇬🇧 [Read in English](README.md)

Настольный калькулятор на C++20 и Qt6 (Widgets) с собственным парсером выражений, историей вычислений и настраиваемым интерфейсом. Архитектура — MVC.

Кроссплатформенность: собирается и работает на Windows, Linux и macOS — в коде нет платформозависимых участков, используются только Qt6 и CMake.

## Функции

- Стандартные операции: `+ - * /`, скобки, унарный минус
- Дополнительные функции: `x²`, `√x`, `1/x`
- История вычислений (можно подставить прошлый результат обратно)
- Настраиваемая точность результата
- Светлая / тёмная тема, сохраняется между запусками
- Ошибки в выражении отлавливаются и показываются пользователю
- Юнит-тесты для парсера (GoogleTest)

## Сборка

**Требования:** компилятор с C++20, CMake ≥ 3.28, Qt6 (Core, Widgets)

```bash
git clone <ссылка_на_репозиторий>
cd <папка_проекта>
cmake -S . -B build -DCMAKE_PREFIX_PATH=<путь_до_Qt6>
cmake --build build -j
```

Запустите исполняемый файл `Calculator` из папки `build`.

Чтобы не собирать тесты (нет интернета / быстрее сборка): добавьте `-DBUILD_TESTING=OFF`.
